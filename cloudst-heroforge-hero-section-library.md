Below is a **Product Catalogue Document** for your Hero Section Library. It is designed for your HTML/CSS/JS visual editor, Bootstrap-template builds, and website revamps. Each hero is a modular, pre-built section that the client or editor can customise with text, media, colours, and a call to action.  
Hero sections generally work best when they communicate one clear offer with a headline, short supporting copy, and a visible call to action; split, centred, background-image, and product-preview layouts are common patterns.

## **5. Testimonial / Social Proof Hero**  
**Use case:** Accountants, lawyers, clinics, agencies, consultants, financial advisers, trades, coaches.  
**Layout:** Fixed headline, description, and CTA, with a rotating or static strip of short client testimonials below the CTA.  
text  
┌─────────────────────────────────────────────┐  
│                 Eyebrow                     │ │                 H1 headline                 │ │              Short description              │ │              Primary CTA                    │ │                                             │ │  \[Avatar\] “Short client quote…”             │ │  \[Avatar\] “Short client quote…”             │ │  \[Avatar\] “Short client quote…”             │ └─────────────────────────────────────────────┘  
## **Variants**  
  
|  |  |  |  
| - | - | - |  
| **Variant** |  **Visual treatment** |  **Best use** |  
| **Static Proof Strip** |  2–3 short testimonials, no rotation |  Most SME websites |  
| **Rotating Testimonial Strip** |  One testimonial fades or slides in every 5–7 seconds |  Trust-heavy services |  
| **Featured Quote Hero** |  One large client quote beside the CTA |  High-ticket services |  
| **Avatar Cloud** |  Multiple client avatars with a rating or review count |  Local service businesses |  
| **Review Badge Hero** |  Google rating, review count, and short quote |  Local businesses |  
| **Testimonial Wall Overlay** |  Background grid of testimonials with headline and CTA overlay |  Agencies, creative businesses |  
| **Video Testimonial Hero** |  Short client video beside the offer |  Premium service providers |  
  
## **Recommended default**  
Use the **Static Proof Strip** as the default. It is easier to read, less distracting, and keeps the CTA visible.  
Use the **Rotating Testimonial Strip** only when the client has at least four strong, short testimonials.  
## **Testimonial rules**  
- Keep each quote to 50–120 characters.  
- Show the client’s first name, business type, or role.  
- Use a real photo only when the client has permission.  
- Keep the H1, description, and CTA fixed.  
- Rotate only the testimonial strip.  
- Pause rotation on hover and keyboard focus.  
- Include a pause/play control when autoplay is enabled.  
- Respect prefers-reduced-motion.  
- Avoid rotating faster than every 5 seconds.  
The W3C carousel guidance specifically requires autoplaying carousels to provide stop and restart controls, and recommends pause-on-hover behaviour for accessibility.
